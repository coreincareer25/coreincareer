# **App Name**: EduPath

## Core Features:

- Course Explorer: Display detailed information about various courses, including prerequisites, curriculum, and career prospects.
- College Profiles: Provide comprehensive profiles of colleges, including academic programs, campus life, admission requirements, and location details.
- Scholarship Database: List various scholarships and financial aid options with eligibility criteria, application deadlines, and award amounts.
- Contact Inquiry Form: Offer a form for users to submit inquiries and contact the counselling services team.
- Services Information: Page describing the educational counseling services
- Personalized Recommendations: A recommendation tool suggesting courses, colleges and/or scholarships based on user's self-reported interests, academic background, and career aspirations.

## Style Guidelines:

- Primary color: HSL 210, 75%, 50% (approximates to RGB #3399FF), reflecting trust and guidance.
- Background color: HSL 210, 20%, 95% (approximates to RGB #F0F8FF), a very light tint for clean presentation.
- Accent color: HSL 180, 65%, 40% (approximates to RGB #26A69A), providing contrast and highlighting important elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif, giving a clean and modern feel.
- Use modern, minimalist icons to represent courses, colleges, and other services.
- Maintain a clean, well-structured layout for easy navigation and readability, similar to coreincareer.in.
- Incorporate subtle transitions and animations for a smooth user experience.
